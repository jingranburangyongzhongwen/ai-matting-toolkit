## 给制作者的约束（务必遵守）

1. **一页只讲一件事**。模型侧（原则→推论）固定两种页：  
   - **原则页**：`是什么` → `为什么大概率不变`；**不写**做法清单，**不堆**例子，**不上屏**边界/失效清单。  
   - **推论页**：**一条推论** → **例子**；例子不限单次 / 多轮 / 跨会话，**凡使用大模型即可**；**不要**再立新「不变」。
2. **标题前缀**：原则用 `模型 ·` / `工程 ·` / `产品 ·`；推论用 `所以 ·`（标明由哪条原则推出）。
3. **只把「上屏」做成幻灯片正文**；「备注」进演讲者备注。
4. **「素材」**：需要配图的页已写死 `report/assets/...` 路径；**禁止**为「工具效果」做前后对比图墙——效果用 URL 现场演示。注意力不均 / 分布拟合 / 各「所以」推论页（「分层拆开改」除外）默认无图。
5. **不要**把「用途 / 约束 / 切分标准 / 配图清单」做成幻灯片。
6. **视觉**：公司内部分享，清晰克制；封面与工具页以文字/URL 为主，不要强塞产品截图。
7. **分页**：原则后 **一推论一页**；宁可页多，也不把多条推论挤回原则页。
8. 英文专有名词保持原样（Prompt、Goal、Agent、Gradio）。
9. **不上屏、不展开**：聊天窗「新开 = 空记忆」——工具产品形态，不是不变原则。
10. **形象边界**：不堆模型名、不讲抠图算法细节、不装视觉专家；算法深度体现在 **LLM 机制 → 可迁移的做法**，例子只用本项目当锚。

### 模型 · 自回归

**上屏**
- **是什么**：逐 token 续写；后面条件于前面
- **直接后果**：早错会滚雪球；「检查自己」也是在既定前文上续写，易自圆其说；前文里有正确锚点，也会顺着续下去
- **为什么大概率不变**：只要还是 next-token 生成，条件依赖就在——换模型、换 Chat/Agent 壳、加长上下文，变的是窗口与界面，不是「后面吃前面」这件事
- （下一页起：一页一条推论）

**备注**
- 金句：错了会越写越歪；前面有锚点，也会顺着写；叫它审自己，也容易圆过去。
- 本页只立原则 + 为何不变；做法与例子全部进「所以」页。
- **别和 RNN 搅在一起**：Transformer **训练**可并行（因果 mask，整段一次性算）；本页钉的是 **推理/生成**——解码仍是一次一个 token，新 token 拼回前文再算下一步。变的是算子与并行度，不是「生成时后面仍条件于前面」。
- 配图：画「推理解码闭环」；不要画 RNN 隐状态绕圈，也不要画多层 Transformer 剖面。

**素材**
- 主图：`report/assets/autoregressive-chain.png` — 生成时的自回归解码（非 RNN）；可加旁注「训练可并行」

### 所以 · 锚点续写（← 自回归）

**上屏**
- **推论**：给对的锚点，续写也更容易对——成熟项目 / 已跑通路径放进前文，比凭空让它设计稳得多
- **例子**：  
  - 去色边：空聊「你设计一套」不成 → 拉相关开源进上下文当锚点，再按本仓库结构改写落地  
  - 粘贴：弱模型自己摸索抽偏 → 强模型先跑通一条带验证的路径留在前文/仓库里 → 再换回弱模型，是在续这条锚点，不是从头发明  
  - 常驻短锚点：端口、别碰打包等写进 **Agent 短规则 / 项目约定**——每次开干自动进条件，等于默认带着正确前缀开写

**备注**
- 贴合机制：条件里有没有「正确前缀」，决定续写往哪走；锚点 = 人为塞进去的正确前缀。
- 例 2 不是训练蒸馏：强模型留下的是可跟随的轨迹（含验证），弱模型在同一任务上续写时更容易照着走。
- 口播可提：有人用 `claude.md` 一类文件承载短规则——形态可变，机制是「常驻正确前缀」。
- 上屏少提具体模块名，避免听成抠图技术分享；需要时备注可点 `rgb_defringe`。

### 所以 · 一次一件事（← 自回归）

**上屏**
- **推论**：一次只续一个可验收目标——多事混着续容易越写越歪；少逐步遥控往前文塞噪声
- **例子**：  
  - 一件事里塞「分割 + 修边 + 打包」→ 改乱、漏约束 → 拆开做  
  - 修布局：Goal 写清要达成什么 + 怎么验收，比一步步遥控改哪一段更快更稳  
  - 定位 bug：先用便宜模型多轮问「还缺什么信息」；信息够了再换强模型修——探路和动手拆开，也更省

**备注**
- 拆开做、Goal、丢掉脏前文、定位/修复分模型——都是「别让条件里同时跑多条互相抢的续写」；上屏三条里可按时长只讲前两条 + bug 这条。
- Goal 口播可补：给完整目标，少逐步遥控——人频繁打断，等于往前文塞噪声、截断推理链。
- 脏前文丢掉 / 粘贴惯性：口播可补；技术锚点 `0264d5a`。
- 「新开窗」若被问到：只是丢弃脏前文的一种操作，不是原则本身。
- 「放哪儿才看得见」→ 注意力不均，不是本条。
- 便宜→强模型：变的是哪家模型；不变的是先把「修」的条件凑齐再续写（也接点锚点续写）。

### 所以 · 外部验真（← 自回归）

**上屏**
- **推论**：别让写代码的那条对话自己当考官——换窗外的来验（新会话、另一模型/Goal 小裁判、脚本、人眼）；验法越笨越好，别整「你再反思一下」
- **例子**（个人工作流）：  
  - **审暂存区**：改完不在同一窗自评 → **新开会话**审 staged diff，上下文隔离  
  - **想并行干别的**：先让模型写出**验证脚本**，再开 **Goal**（小模型裁判 + 自动跑验收）盯到完成——墙钟时间往往更长，但不占用我手动点验，可以去干别的事  
  - 本项目同构：粘贴靠跑页面钉死 Gradio 行为；两 Tab 布局靠可跑脚本验收

**备注**
- 金句：法官不要和被告共用一段前文；能把验真外包给脚本/Goal，人就从「盯梢」里解放出来。
- 可再钉一句：**生成变快了，验真没变便宜**——所以更要把考官挪到窗外。
- Goal 耗时长但省心：换的是人的注意力，不是省略验真。
- 强度大致：环境事实 ≥ 脚本 ≥ Goal 小模型裁判 ≥ 同模型新会话审 diff。
- 固化进仓库的脚本 ↔ 工程 · commit 与验收；口播可点 `scripts/measure_*.py`、`0264d5a`，上屏不必堆路径。

### 所以 · 坑写代码旁（← 注意力不均）

**上屏**
- **推论 / 该怎么做**：局部踩坑经验写在相关代码旁——需要才加载；一旦改到这块，注释和代码同屏，比埋在长聊天腰部更不容易丢
- **例子**（得到的好处）：  
  - 粘贴上传那个坑：写进相关 UI 文件后，平时不塞进全局聊天；真改上传时打开文件才带上，很少再走回头路  
  - 文件职责、迭代踩坑跟着文件走：Agent 动到哪一段，就加载哪一段的说明——少靠「我记得哪次聊天说过」，也少在无关任务里被旧坑叙事干扰

**备注**
- 金句：需要才加载；加载时又在最新读到的那截里，两头都占优。旧称「抢落点」= 同一做法。
- 技术锚点（备注）：粘贴坑 → `layout.py` / `events.py`，曾反复发明回 Base64。
- 做法（口播）：文件头写职责 + 踩坑史；重要函数旁补短注。
- 若被问到「长 Prompt 关键约束放哪」：口播一句——靠上下文两头，少埋腰部；与本页「旁注」是同一不均匀性下的两种落点，上屏不展开。
- 和常驻短规则分工：几乎每次都要用的 → 短规则；局部才要用的 → 旁注（需要才加载）。
- 工程侧只讲高内聚低耦合；旁注不单开工程页。

### 模型 · 分布拟合

**上屏**
- **是什么**：训练拟合的是数据上的条件分布，不是唯一标准答案；生成会往分布里概率高的区域靠——常见、通用的解更容易出现
- **为什么大概率不变**：只要还是按似然/交叉熵一类目标学「什么续写常见」，众数偏好就在；换模型、换壳，变的是分布形状，不是变成背题查表
- （下一页：推论）

**备注**
- **不是「概率输出」的子条**：偏大众来自**训练学了什么分布**；就算不随机采样、走贪心，也常落到高频解上。
- 「loss 到不了 0」可口播成直觉；更干净的说法是 MLE 学条件分布 → 高概率区域占优。
- 和概率输出衔接：学的是分布，推理才从分布里抽——一个管「分布长什么样」，一个管「这一次怎么抽」。

**上屏**
- **推论 / 该怎么做**：关键方案别全仰赖大模型——默认容易落「大家都这么做」；小众但更对的路，**自己先想透，再交模型落地**
- **例子**：去色边——模型反复提「全局优化」一类常见说法；**涂抹局部处理**是按产品形态自己想出来的，再当锚点让模型实现

**备注**
- 金句：动手可以靠它，想清楚省不得。
- 限定一句（重要）：不全是「分布偏大众」四个字能概括——也有训练语料里任务被说成全局优化的惯性；跨界时更常见的是**关键选型自己想清楚，再让模型落地**。
- 和「锚点续写」：大众解是分布默认；锚点用来把续写拽到小众正确轨迹上——本页讲为何思考省不得，锚点页讲怎么拽。
- 和「多候选再选」：多问几遍仍可能都是大众解；小众路线有时得人先想出来。

### 模型 · 概率输出

**上屏**
- **是什么**：每次生成是一次采样，不是查表；同一条件下可以抽出好样本，也可以抽出坏样本
- **为什么大概率不变**：解码仍是从（已学到的）分布里抽——调温度、换采样器、换模型，变的是抽法与分布形状，不是变成确定性检索

**备注**
- 和自回归分工：自回归 = 条件依赖（前文形状）；概率 = 这一次是抽样（同一条件下仍有方差）。

### 所以 · 逐步加约束（← 概率输出）

**上屏**
- **推论 / 该怎么做**：抽偏了就加禁令、收窄条件再试——别用单次采样给能力下死刑；变的是约束（采样空间），不是「模型突然会了」
- **例子**：中栏粘贴——不是「做不了」，是**条件没收窄**  
  - 第一次：顺手改打包、甚至删功能称修好了 → 否决  
  - 加上「别碰打包」再试 → 还是越界  
  - 继续加「只动 UI、禁止删功能」……**不让做什么**越写越清，才得到能用的改法

**素材**
- 主图：`report/assets/galton-baffle.png` — 高尔顿板左右对比（无约束 vs 加挡板）；**上屏配「所以 · 逐步加约束」**；本原则页口播可用

**备注**
- 金句：逐步加禁令，是在收窄采样空间，不是给模型补课；离谱就撤掉重来，别和坏回复抬杠。
- 旧称「答错≠不会」是认知纠偏，可作口播；上屏用行为名「逐步加约束」。
- 钉死概念：本例主操作是**改条件**，不是 Best-of-N；Best-of-N 在下一页。
- 和自回归「锚点续写」：有时也是条件里没有可续的正确轨迹。
- 卡死时可换模型/换说法——那是换分布，口播一句即可。
- 高尔顿板图配本页：挡板 = 约束。

### 所以 · 多候选再选（← 概率输出）

**上屏**
- **推论**：生成变便宜时，与其迷信单发，不如多抽几个候选，用便宜的验真器挑一个
- **例子**：调研 / 收敛路线阶段——同一问题问多个模型，甚至同一模型多问几遍；把路径摊开对比，再收成「做什么 / 不做什么」，而不是死磕第一次回答

**备注**
- Best-of-N 的朴素版：随机性当资源；验真可以是人眼对比、对照开源、或短跑通。
- 和「逐步加约束」分工：那边是坏了再来、逐步加禁令；本页是故意多抽再挑。
- 开发中同一 Goal 出两版再看 diff：口播可补，上屏用调研阶段更贴个人习惯。
- 某一模型反复同质抽偏：换模型或换条件（如塞开源）再采——与「锚点续写」重叠，口播带过。
